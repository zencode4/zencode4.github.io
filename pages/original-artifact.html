ORIGINAL ARTIFACT

Grazioso Salvare Animal Rescue Dashboard

Originally developed for CS 340 Client/Server Development

Original Artifact Overview

The original artifact is the Grazioso Salvare Animal Rescue Dashboard developed during CS 340. The application connects a Dash web interface with a MongoDB database to display, filter, and visualize animal rescue records. It includes a searchable data table, interactive charts, and a geographic map for displaying rescue locations.

Why This Artifact Was Selected

This project was selected because it provided opportunities for meaningful enhancement across multiple areas of computer science. The application already demonstrated database connectivity, visualization, and user interaction, making it an ideal candidate for software engineering, algorithms and data structures, and database improvements while preserving the original functionality.

Original Technologies

  • Python
  • Dash / JupyterDash
  • MongoDB
  • Pandas
  • Plotly
